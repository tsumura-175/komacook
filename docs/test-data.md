# ローカル用テストデータ

このファイルに記載するアカウントとパスワードは、ローカル開発環境専用です。本番環境には投入しません。

## テストアカウント

| 用途 | メールアドレス | パスワード | 表示名 |
| --- | --- | --- | --- |
| 管理者 | `admin@komacook.local` | `Komacook!Admin2026` | こまクック公式 |
| 一般会員 | `user@komacook.local` | `Komacook!User2026` | こまさん |
| 公開レシピ投稿者 | `mama@komacook.local` | `Komacook!Mama2026` | はるママ |

3アカウントはメール確認済みかつ、利用規約・プライバシーポリシー・投稿ガイドラインの現行版へ同意済みとして作成されます。管理者には `admin` ロールを設定しています。

3アカウントは初回設定完了済みです。初回設定画面、登録時プロフィール画像、メール確認待ちを検証する場合は、既存アカウントを変更せず、`/login`から一時的な新規会員を作成してください。確認メールはMailpit（http://127.0.0.1:55324）で確認できます。

## リセットで作成されるデータ

- 会員プロフィール: 3件
- 固定カテゴリ: 10件
- レシピ: 9件
  - 公開・公開中: 4件
  - 非公開・公開中: 3件（手入力2件、他者レシピのコピー1件）
  - 非公開・下書き: 1件
  - ごみ箱: 1件
- 材料: 25件
- 手順: 19件
- タグ: 10件
- 保存したレシピ
- 管理者からのお知らせ: 2件
- 通報: 1件
- 問い合わせ送信ログ: 1件
- Storageバケット: `avatars`、`recipe-images`

一般会員でログインすると、公開レシピ4件と本人のレシピ5件を確認できます。未ログイン状態では公開中の4件だけを参照できます。

## 再作成方法

Docker DesktopとローカルSupabaseを起動した状態で、次を実行します。

```powershell
npm run supabase:reset
```

このコマンドはローカルDBの既存データを削除し、`supabase/migrations`、`supabase/seed.sql` の順に適用します。
